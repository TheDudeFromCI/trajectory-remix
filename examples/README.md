# Examples

- [graph_minimal.json](graph_minimal.json): detached graph source for import.
- [graph_tools.json](graph_tools.json): fragmented synthetic tool exchange.
- [graph_local_llm.json](graph_local_llm.json): endpoint-role configuration template;
  use your own URLs/models and keep authentication in the server environment.
- [ktremix_dataset.py](ktremix_dataset.py): public binary dataset reader/sampler.
- [ktremix_training_data.py](ktremix_training_data.py) and
  [train_ktremix.py](train_ktremix.py): real-compiler letter-addition demo.

Read [local-model validation](../docs/GRAPH-LOCAL-LLM.md),
[training instructions](../docs/KTREMIX-TRAINING-DEMO.md) and
[acceptance](../docs/ACCEPTANCE.md) before explicitly starting model work.
These scripts do not run during ordinary test collection.
